# MOBILE SALES DASHBOARD
This project is an interactive Mobile Sales Dashboard created using Power BI to analyze sales performance, transactions, customer ratings, and payment methods across different cities and mobile brands.

Key Features
Interactive KPI cards for Total Sales, Transactions, Quantity, and Average Price
Sales analysis by city, month, mobile model, and day name
Customer rating and payment method insights
Dynamic filters/slicers for better data exploration
Data visualization using charts, maps, and tables
Tools & Technologies Used
Power BI
Power Query
DAX
Data Visualization
Insights Generated
Identified top-performing mobile brands and cities
Analyzed monthly sales trends and transaction patterns
Compared customer ratings and payment preferences

This project helped me improve my skills in dashboard design, data visualization, and business analytics using Power BI.
