# 📱 Mobile Sales Dashboard using Power BI

An interactive Power BI dashboard designed to analyze mobile sales performance, customer ratings, transactions, and payment methods across different cities and brands.

## 🔹 Features
- KPI cards for Total Sales, Transactions, Quantity, and Average Price
- Sales analysis by city, month, mobile model, and day
- Customer rating insights
- Payment method distribution analysis
- Interactive slicers and filters for dynamic exploration

## 🛠️ Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization

## 📊 Insights
- Identified top-performing brands and cities
- Analyzed monthly sales and transaction trends
- Compared customer ratings and payment preferences

This project helped strengthen my skills in dashboard design, business analytics, and data visualization using Power BI.
